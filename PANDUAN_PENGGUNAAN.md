# BAGIAN 1: PANDUAN PENGGUNAAN WEBSITE UTAMA (PUBLIK)

Website publik SIPANDU dapat diakses langsung oleh seluruh masyarakat, pegawai, maupun instansi luar melalui peramban web (browser).

```
+-----------------------------------------------------------------------------------------------+
| [LOGO KEMENDIKDASMEN]  |  Beranda  |  Fitur  |  Statistik  |  Fasilitas  |  Kontak  |  [Masuk] [Daftar] |
+-----------------------------------------------------------------------------------------------+
```

### 1.1 Navigasi Navbar & Menu Beranda
1. **Logo & Identitas Instansi**: Menampilkan logo resmi Kemendikdasmen dan BPMP Provinsi Gorontalo. Klik logo untuk kembali ke posisi teratas halaman.
2. **Menu Beranda (`#hero`)**: 
   - Menampilkan pengenalan sistem SIPANDU.
   - **Tombol "Masuk Sekarang"**: Tombol pintas untuk langsung diarahkan ke halaman login.
   - **Tombol "Pelajari Fitur"**: Mengarahkan halaman ke bagian penjelasan modul-modul sistem.
   - **Slider Galeri Foto**: Menampilkan foto fasilitas lingkungan kantor BPMP Gorontalo (Kantor Utama, Kantor Ponuwa, Gedung Aula, Gedung Tinelo).

### 1.2 Mengecek Fitur & Statistik BMN
1. **Menu Fitur (`#fitur`)**:
   - Menampilkan ringkasan 5 modul utama: *Pencatatan Persediaan, Pengelolaan Aset Tetap, Peminjaman & Pengembalian, Laporan & Analitik, serta Multi-Role Access*.
2. **Menu Statistik (`#statistik`)**:
   - Menampilkan 4 kartu indikator transparansi BMN secara real-time:
     - **Total Item BMN**: Jumlah total inventaris barang terdaftar.
     - **Nilai Aset Terkelola**: Akumulasi nilai perolehan kapitalisasi BMN (dalam Miliar Rupiah).
     - **Transaksi Bulan Ini**: Total aktivitas transaksi logistik/aset pada bulan berjalan.
     - **Persentase Kondisi Baik**: Rasio aset siap pakai layak operasi.

### 1.3 Melihat & Mengecek Fasilitas Gedung
1. **Menu Fasilitas (`#fasilitas`)**:
   - Menampilkan katalog gedung, ruang aula, dan ruang rapat BPMP Gorontalo.
2. **Melihat Detail Gedung**:
   - Arahkan kursor atau sentuh kartu fasilitas untuk melihat kapasitas orang, fasilitas ruangan (AC, Sound System, Proyektor), dan ketersediaan.
   - Klik **"Lihat Detail"** pada kartu gedung untuk membuka galeri foto lengkap dan informasi tata cara peminjaman.

### 1.4 Menghubungi Kontak & Lokasi
1. **Menu Kontak (`#kontak`)**:
   - Menampilkan alamat kantor BPMP Provinsi Gorontalo, nomor telepon/WhatsApp layanan sarpras, dan email resmi untuk keperluan koordinasi atau pengajuan surat permohonan dinas.

### 1.5 Cara Melakukan Pendaftaran Akun (Registrasi)
1. Pada menu navigasi atas, klik tombol **"Daftar"**.
2. Anda akan diarahkan ke halaman registrasi (`/daftar`).
3. Masukkan data yang diminta:
   - **Nama Lengkap**
   - **Username**
   - **Nomor Telepon / WhatsApp**
   - **Kata Sandi (Password)** dan Konfirmasi Password.
4. Klik tombol **Daftar Akun**.
5. Akun Anda berhasil terdaftar dan dapat digunakan untuk masuk/login.

### 1.6 Cara Masuk / Login ke Sistem
1. Pada menu navigasi atas, klik tombol **"Masuk"** (atau buka URL `/login`).
2. Masukkan **Username** dan **Password** Anda.
3. (Opsional) Centang **"Ingat Saya"** agar sesi login tersimpan.
4. Klik **Masuk**.
5. Sistem secara otomatis mendeteksi role/peran Anda dan langsung membuka Dashboard kerja sesuai hak akses yang dimiliki.

# BAGIAN 2: PANDUAN FUNGSI MENU UTAMA SETIAP ROLE

---

## 2.1 ROLE: KEPALA BPMP
> **Tujuan Peran**: Pemantauan eksekutif, rekapitulasi inventaris BMN, dan pengunduhan laporan resmi pimpinan.

| Menu Utama | Sub-Menu | Fungsi & Tata Cara Penggunaan |
| :--- | :--- | :--- |
| 📊 **Dashboard** | — | Meninjau ringkasan visual kondisi fisik aset (Baik, Rusak), kapitalisasi nilai aset, dan mutasi data terkini. |
| 📑 **Laporan BMN** | — | Membuka tabel komprehensif seluruh inventaris aset dan persediaan; gunakan filter tanggal, unit kerja, atau kategori untuk memilah data. |
| 📥 **Download Laporan** *(Dropdown)* | **Laporan Persediaan** | Mengunduh berkas laporan mutasi dan stok barang persediaan/ATK dalam format PDF. |
| | **Laporan Aset Tetap** | Mengunduh buku inventaris aset tetap beserta nilai perolehan dan penyusutan dalam format PDF. |
| | **Laporan Sarpras** | Mengunduh rekapitulasi sarana prasarana, status gedung, dan riwayat kerusakan dalam format PDF. |
| | **Laporan Lengkap** | Mengunduh laporan gabungan konsolidasi seluruh BMN dalam satu dokumen PDF resmi. |
| ⚙️ **Pengaturan Akun** | — | Mengatur profil pribadi, mengganti kata sandi, dan mengunggah tanda tangan digital untuk penyematan pada lembar pengesahan laporan. |

---

## 2.2 ROLE: KASUBAG UMUM
> **Tujuan Peran**: Otorisasi persetujuan (*approval*) berjenjang untuk peminjaman sarana dan pengeluaran barang persediaan.

| Menu Utama | Sub-Menu | Fungsi & Tata Cara Penggunaan |
| :--- | :--- | :--- |
| 📊 **Dashboard** | — | Meninjau jumlah antrean pengajuan yang menunggu persetujuan (*Pending Approval*). |
| ✅ **Manajemen Persetujuan** *(Dropdown)* | **Peminjaman Barang** | Memeriksa berkas permohonan pinjam alat dari pegawai $\rightarrow$ Klik **Setujui (Approve)** atau **Tolak (Reject)** dengan alasan. |
| | **Peminjaman Kendaraan** | Memeriksa jadwal dinas, rute perjalanan, pengemudi, dan alokasi BBM $\rightarrow$ Otorisasi persetujuan armada mobil/motor dinas. |
| | **Permintaan Persediaan** | Memeriksa rincian item ATK yang diminta unit kerja $\rightarrow$ Menyetujui atau menolak pengeluaran logistik dari gudang. |
| ⚙️ **Pengaturan Akun** | — | Mengelola profil, password, dan tanda tangan digital untuk penyematan otomatis pada lembar disposisi. |

---

## 2.3 ROLE: ADMIN ASET TETAP
> **Tujuan Peran**: Pengelolaan siklus hidup BMN / aset tetap dari pencatatan, peminjaman, mutasi, hingga pengeluaran.

| Menu Utama | Sub-Menu | Fungsi & Tata Cara Penggunaan |
| :--- | :--- | :--- |
| 📊 **Dashboard** | — | Menampilkan statistik jumlah aset, total nilai aset, rasio kondisi baik, dan grafik transaksi masuk/keluar. |
| 🗄️ **Data Aset Tetap** | — | • Master data inventaris aset tetap (Kode BMN, NUP, Merk/Tipe, Lokasi Ruangan).<br>• Tambah aset baru secara manual.<br>• Gunakan **Import Excel** & **Download Template** untuk upload data massal.<br>• Cetak label barcode aset. |
| 📥 **Transaksi Masuk** | — | Mencatat pengadaan baru, hibah masuk, atau transfer masuk aset (Supplier, No. Faktur/BAST, Nilai Perolehan). |
| 📤 **Transaksi Keluar** | — | Mencatat penghapusan aset, lelang, hibah keluar, atau pemusnahan barang rusak berat. |
| 🔄 **Mutasi Barang** | — | Mencatat pemindahan fisik aset antar ruangan atau penanggung jawab baru di lingkungan kantor. |
| 📋 **Info Ajuan Mutasi** | — | Memverifikasi dan menindaklanjuti permohonan mutasi aset yang diajukan oleh pegawai. |
| 🔄 **Manajemen Peminjaman** *(Dropdown)* | **Peminjaman Barang** | Memverifikasi ketersediaan barang pinjaman, mencetak BAST Pinjam Pakai, dan mengunggah dokumen bertandatangan. |
| | **Peminjaman Kendaraan** | Memverifikasi armada mobil/motor dinas, penunjukan sopir, dan menerbitkan Surat Izin Peminjaman Kendaraan. |
| ↩️ **Manajemen Pengembalian** *(Dropdown)* | **Pengembalian Barang** | Mengecek kondisi fisik aset yang dikembalikan pegawai (baik/rusak/hilang), verifikasi selesai, dan cetak bukti pengembalian. |
| | **Pengembalian Kendaraan** | Menginput KM akhir kendaraan, kondisi fisik armada, konfirmasi pengembalian STNK/kunci, dan verifikasi selesai. |
| 📈 **Laporan & Statistik** *(Dropdown)* | **Ringkasan & Analitik** | Dashboard analitik grafik pergerakan aset dan depresiasi BMN. |
| | **Laporan Transaksi Keluar** | Rekapitulasi detail transaksi pengeluaran/penghapusan aset (Download PDF/Excel). |
| ⚙️ **Pengaturan Akun** | — | Mengubah data profil, password, dan tanda tangan digital admin aset. |

| Menu Utama | Sub-Menu | Fungsi & Tata Cara Penggunaan |
| :--- | :--- | :--- |
| 📊 **Dashboard** | — | Menampilkan peringatan otomatis stok menipis (di bawah batas minimum), total item katalog, dan mutasi barang per bulan. |
| 🗄️ **Data Persediaan** | — | • Katalog master persediaan (Kode barang, nama item, satuan, harga perolehan, batas minimum stok).<br>• **Import Excel** & **Download Template** data persediaan. |
| 📋 **Stok Opname Bulanan** | — | • Buat sesi opname fisik bulanan.<br>• Input stok riil gudang $\rightarrow$ sistem menghitung otomatis selisih fisik vs sistem.<br>• Klik **Finalisasi Opname** dan cetak Berita Acara Stok Opname. |
| 📥 **Transaksi Masuk** | — | Mencatat penerimaan barang dari rekanan/supplier (menambah stok gudang otomatis). |
| 📤 **Transaksi Keluar** | — | Mencatat pengeluaran barang mandiri non-permintaan untuk kebutuhan operasional darurat (mengurangi stok otomatis). |
| 🔄 **Manajemen Permintaan** *(Dropdown)* | **Permintaan Persediaan** | Memverifikasi permohonan ATK dari unit kerja, cek ketersediaan stok sebelum diteruskan ke Kasubag, dan mencetak Surat Bukti Penyerahan / BAST. |
| 📈 **Laporan & Statistik** *(Dropdown)* | **Laporan Transaksi Masuk** | Mencetak riwayat penerimaan barang dari vendor (Download PDF). |
| | **Laporan Transaksi Keluar** | Mencetak rekapitulasi penyaluran logistik (Download PDF). |
| | **Laporan Permintaan** | Mencetak rekap permintaan per unit kerja/bidang (Download PDF). |
| ⚙️ **Pengaturan Akun** | — | Mengubah profil, password, dan tanda tangan digital admin persediaan. |

# BAGIAN 3: STANDAR OPERASIONAL PROSEDUR (SOP) & ALUR KERJA

```
1. PEMINJAMAN BARANG & KENDARAAN DINAS:
   [ Pegawai ] -> Mengajukan di menu Peminjaman Barang / Kendaraan
        ↓
   [ Admin Aset Tetap ] -> Verifikasi ketersediaan barang/armada
        ↓
   [ Kasubag Umum ] -> Setujui / Tolak di menu Manajemen Persetujuan
        ↓
   [ Pegawai ] -> Menggunakan aset -> Mengajukan di menu Pengembalian
        ↓
   [ Admin Aset Tetap ] -> Cek fisik, KM akhir, verifikasi Selesai

2. PERMINTAAN BARANG PERSEDIAAN (ATK):
   [ Pegawai ] -> Mengajukan di menu Permintaan Persediaan
        ↓
   [ Admin Persediaan ] -> Cek ketersediaan stok gudang
        ↓
   [ Kasubag Umum ] -> Setujui pengeluaran di menu Manajemen Persetujuan
        ↓
   [ Admin Persediaan ] -> Penyerahan barang (stok otomatis berkurang) & Cetak BAST

3. PEMINJAMAN GEDUNG (TAMU EKSTERNAL):
   [ Tamu ] -> Buka website -> Cek Fasilitas -> Daftar/Masuk -> Ajukan Peminjaman Gedung (+ Upload Surat)
        ↓
   [ Admin Sarpras ] -> Cek jadwal & kesiapan ruangan
        ↓
   [ Kasubag Umum ] -> Menyetujui permohonan sewa
        ↓
   [ Admin Sarpras ] -> Terbitkan Surat Izin Pemakaian Gedung
```
